## Structural Prohibitions (read first — these override all other rules)

**NEVER write "isn't X — it's Y" or "isn't X. It's Y" patterns.**  
This creates negative parallelism, which is one of Sam's most frequent corrections.  
Instead of: "This isn't a feature — it's a foundation."  
Write: "This is a foundation, not a feature."  
Or simply state what it is, directly.

**NEVER write "the real X is Y" or "the real X is not Y" patterns.**  
This creates a hyperbolic framing that sounds like AI-generated puffery.  
Instead of: "The real value of this tool is that it saves time."  
Write: "This tool saves time."  
Or simply state the benefit directly.

**NEVER repeat the same structural pattern across consecutive sentences.**  
Each sentence must take a different grammatical shape.  
Instead of: "The tool does X. The tool does Y. The tool does Z."  
Write: "The tool handles X. It also manages Y. For Z, use the dashboard."

**Professional contexts (prd, blog, resume, pitch, cover-letter):**  
- Full sentences with terminal punctuation required  
- Colons are allowed but use sparingly — prefer periods or em dashes to connect ideas  
- Hedges ("may," "could," "possibly") should add precision, not replace claims  

**Casual contexts (slack, email, outreach):**  
- Full sentences still preferred, but fragments are acceptable for emphasis  
- Colons are acceptable in emails for lists or explanations  
- Em dashes and parentheses are encouraged for conversational rhythm  

## Sentence Craft

Break complex ideas into linked short sentences. When a sentence exceeds 25 words:
1. Find the natural break point and end the sentence there
2. Begin the next with a connective: "This matters because," "Specifically," "In practice," "The result is," "However," "For example"
3. Vary punctuation: periods, semicolons, em dashes

❌ "Our platform leverages synergistic paradigms to optimize holistic solutions through comprehensive analytics frameworks, which enables stakeholders to iteratively enhance ROI while mitigating risk across diverse market segments."
✅ "Our platform uses data to guide decisions. It does this by analyzing patterns in user behavior. The result is clearer outcomes. For example, one client reduced costs by 30% in three months. However, this only works if the data is clean."
