## Structural Prohibitions (read first — these override all other rules)

**NEVER write "isn't X — it's Y" or "isn't X. It's Y" patterns.**  
This creates negative parallelism, which is one of Sam's most frequent corrections.  
Instead of: "This isn't a feature — it's a foundation."  
Write: "This is a foundation, not a feature."  
Or simply state what it is, directly.

**NEVER write "the real X is Y" or "the real X is not Y" patterns.**  
This creates a hyperbolic framing that sounds like AI-generated puffery.  
Instead of: "The real value of this tool is that it saves time."  
Write: "This tool saves time."  
Or simply state the benefit directly.

**NO sentence may exceed 25 words. Break complex ideas into linked short sentences.**  
Each sentence must be a complete thought. When you feel a sentence getting long, end it and begin the next with a connective: "This matters because," "Specifically," "In practice," "The result is," "However," "For example."

**NO repetitive sentence structure.** Each sentence must take a different grammatical shape.  
Instead of: "The tool does X. The tool does Y. The tool does Z."  
Write: "The tool handles X. It also manages Y. For Z, use the dashboard."

**Full sentences with terminal punctuation required** in professional contexts.
