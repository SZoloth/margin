## Why this matters

`CommandPalette.tsx` renders FTS5 search snippets directly into the DOM via
`dangerouslySetInnerHTML={{ __html: result.snippet }}` without sanitizing the
string. The snippet is generated by SQLite's `snippet()` function with `<mark>`
and `</mark>` as delimiters — content comes from document text that the user
controls. A malicious document could embed `<script>` or `<img onerror=...>`
tags, which would execute in the Tauri webview context (same origin as the
app itself, full access to Tauri invoke APIs).

The Sidebar component already has a correct `sanitizeSnippet()` function for
exactly this purpose — the fix is to apply the same sanitizer in CommandPalette.
The attack surface is limited to files the user opens, but defense-in-depth
matters for a portable desktop app.

## Steps

### Step 1: Create `src/lib/sanitize-snippet.ts`

Extract the function from Sidebar.tsx into a shared module:

```typescript
// src/lib/sanitize-snippet.ts

/**
 * Sanitize an FTS5 snippet that contains <mark>/<\/mark> delimiters.
 * Escapes all HTML characters except the allowed <mark> wrappers.
 * Used by any component that renders search snippets via dangerouslySetInnerHTML.
 */
export function sanitizeSnippet(html: string): string {
  return html
    .replace(/<mark>/g, "\x00MARK_OPEN\x00")
    .replace(/<\/mark>/g, "\x00MARK_CLOSE\x00")
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/\x00MARK_OPEN\x00/g, "<mark>")
    .replace(/\x00MARK_CLOSE\x00/g, "</mark>");
}
```

### Step 4: Write tests for `sanitize-snippet.ts`

Create `src/lib/__tests__/sanitize-snippet.test.ts`:

```typescript
import { describe, it, expect } from "vitest";
import { sanitizeSnippet } from "../sanitize-snippet";

describe("sanitizeSnippet", () => {
  it("preserves <mark> and </mark> tags", () => {
    expect(sanitizeSnippet("hello <mark>world</mark> foo")).toBe(
      "hello <mark>world</mark> foo"
    );
  });

  it("escapes < and > that are not mark tags", () => {
    expect(sanitizeSnippet("<script>alert(1)</script>")).toBe(
      "&lt;script&gt;alert(1)&lt;/script&gt;"
    );
  });

  it("escapes & characters", () => {
    expect(sanitizeSnippet("a & b")).toBe("a &amp; b");
  });

  it("escapes double quotes", () => {
    expect(sanitizeSnippet('say "hello"')).toBe("say &quot;hello&quot;");
  });

  it("handles mixed mark tags and HTML", () => {
    const input = '<mark>foo</mark> <script>bad()</script>';
    const result = sanitizeSnippet(input);
    expect(result).toContain("<mark>foo</mark>");
    expect(result).not.toContain("<script>");
    expect(result).toContain("&lt;script&gt;");
  });

  it("is identity on plain text", () => {
    expect(sanitizeSnippet("plain text no markup")).toBe("plain text no markup");
  });

  it("handles empty string", () => {
    expect(sanitizeSnippet("")).toBe("");
  });
});
```

**Verify**: `pnpm test -- sanitize-snippet` → all 7 tests pass
